# ملخص مشروع دفتر الحليب (MilkApp)

## نبذة عامة

تطبيق **دفتر الحليب** هو تطبيق موبايل مبني بـ Flutter لإدارة عمليات جمع الحليب اليومية. يستهدف التطبيق جامعي الحليب (التجار) الذين يستقبلون الحليب من عدة موردين بشكل يومي ويحتاجون لتتبع الكميات وإصدار تقارير أسبوعية.

## التقنيات المستخدمة

- **Flutter** (SDK ^3.11.5) — إطار العمل الأساسي
- **Firebase** — المصادقة (Auth) وقاعدة البيانات (Cloud Firestore)
- **flutter_bloc / Cubit** — إدارة الحالة
- **get_it** — حقن التبعيات (Dependency Injection)
- **go_router** — التنقل بين الشاشات
- **easy_localization** — دعم اللغة العربية والإنجليزية
- **fl_chart** — الرسوم البيانية والإحصائيات
- **pdf + printing** — إنشاء تقارير PDF
- **share_plus** — المشاركة عبر واتساب وغيره
- **connectivity_plus** — مراقبة الاتصال بالإنترنت
- **shared_preferences** — التخزين المحلي

## الميزات الحالية

### 1. المصادقة
- تسجيل دخول وإنشاء حساب جديد
- استعادة كلمة المرور
- شاشة تعريفية (Onboarding)

### 2. لوحة التحكم (Dashboard)
- عرض إحصائيات اليوم والأسبوع
- تنبيهات الغياب للموردين المتغيبين
- بطاقات ملخص الأوزان

### 3. استقبال اليوم
- تسجيل كميات الحليب لكل مورد حسب ترتيب المسار
- تعديل الأوزان مع تسجيل سبب التعديل
- تسجيل حالة "لا حليب اليوم" للمورد
- عرض تفاصيل كل إدخال

### 4. إدارة الموردين
- إضافة وتعديل بيانات الموردين (الاسم، الهاتف، القرية، العنوان)
- ترتيب المسار (Route Ordering) لتحديد أولوية الاستقبال
- تفعيل/تعطيل الموردين
- عرض إحصائيات آخر 7 أيام والإحصائيات الشهرية

### 5. التقارير الأسبوعية
- قائمة التقارير الأسبوعية
- تفاصيل كل تقرير مع جدول الكميات
- إمكانية تصدير التقارير كـ PDF

### 6. الإعدادات
- تبديل اللغة (عربي/إنجليزي)
- تسجيل الخروج

## هيكلية المشروع

```
lib/
  main.dart                    — نقطة البداية
  app.dart                     — ويدجت التطبيق الرئيسي
  core/
    constants.dart             — الثوابت
    theme/                     — المظهر
    cubits/connectivity/       — مراقبة الاتصال
    widgets/                   — ويدجتات مشتركة
  shared/models/               — النماذج المشتركة (Supplier, MilkEntry, WeeklyReport)
  features/
    auth/                      — المصادقة
    dashboard/                 — لوحة التحكم
    today/                     — استقبال اليوم
    suppliers/                 — إدارة الموردين
    reports/                   — التقارير الأسبوعية
    settings/                  — الإعدادات
    shell/                     — الهيكل الرئيسي (Bottom Navigation)
  router/app_router.dart       — إعدادات التنقل
```

## بنية Firestore

```
users/{uid}/
  suppliers/       — بيانات الموردين
  milk_entries/    — إدخالات الحليب اليومية
  weekly_reports/  — التقارير الأسبوعية
```

# نصائح لتطوير وتحديث التطبيق

## تحسينات ذات أولوية عالية

### 1. دعم العمل بدون إنترنت (Offline-First)
- التطبيق حاليا يعتمد على Firestore بشكل كامل. فعّل خاصية **Firestore Offline Persistence** بشكل صريح حتى يتمكن المستخدم من تسجيل الكميات حتى في المناطق التي لا يوجد فيها إنترنت (مزارع بعيدة مثلا).
- أضف مؤشر مزامنة واضح يُعلم المستخدم أن البيانات في انتظار الرفع.

### 2. إضافة سعر الحليب والحسابات المالية
- أضف حقل **سعر الكيلو** لكل مورد أو كسعر عام.
- أضف حساب المستحقات الأسبوعية/الشهرية تلقائيا (الكمية × السعر).
- هذه الميزة ضرورية جدا لأن الهدف النهائي هو الدفع للموردين.

### 3. تصدير ومشاركة التقارير
- وسّع خاصية PDF لتشمل تقارير شهرية وكشف حساب لكل مورد.
- أضف إمكانية إرسال كشف الحساب مباشرة عبر واتساب لكل مورد.

### 4. النسخ الاحتياطي واستعادة البيانات
- أضف خيار تصدير البيانات كملف Excel أو CSV.
- أضف خيار استيراد بيانات سابقة عند تبديل الجهاز.

## تحسينات تجربة المستخدم

### 5. إضافة بحث وفلترة متقدمة
- بحث في الموردين بالاسم أو القرية.
- فلترة الإدخالات حسب التاريخ أو المورد أو نطاق الكمية.

### 6. إشعارات ذكية (Push Notifications)
- تنبيه صباحي لتذكير ببدء جولة الاستقبال.
- تنبيه عند غياب مورد لعدة أيام متتالية.
- تنبيه عند اقتراب نهاية الأسبوع لتأكيد التقرير.

### 7. الوضع المظلم (Dark Mode)
- التطبيق حاليا يدعم ثيم واحد فقط. أضف الوضع المظلم لراحة العين أثناء الاستخدام الصباحي الباكر.

### 8. ويدجت الشاشة الرئيسية (Home Screen Widget)
- أضف ويدجت صغير يعرض ملخص اليوم (عدد الموردين المستلم منهم / الإجمالي، الكمية الكلية) بدون فتح التطبيق.

## تحسينات تقنية

### 9. إضافة اختبارات
- المشروع حاليا بدون اختبارات وحدة (Unit Tests) أو اختبارات ويدجت. أضف اختبارات على الأقل للـ Cubits ولطبقة البيانات.

### 10. تحسين الأمان
- أضف **Firestore Security Rules** محكمة لضمان أن كل مستخدم يصل فقط لبياناته.
- أضف حد أقصى لعدد الإدخالات اليومية لمنع الأخطاء.

### 11. تحسين الأداء
- أضف **Pagination** لقوائم الموردين والإدخالات عندما يزيد عدد البيانات.
- استخدم **Firestore Indexes** المركبة لتسريع الاستعلامات.

### 12. إعداد Flavors و CI/CD
- المشروع حاليا بدون Product Flavors. أضف بيئات dev/staging/production.
- أضف Fastlane و GitHub Actions للنشر التلقائي على Firebase App Distribution.

### 13. دعم منصة iOS
- تأكد من اختبار التطبيق على iOS وإصلاح أي مشاكل خاصة بالمنصة.
- جهّز إعدادات App Store Connect للنشر مستقبلا.

## ميزات مستقبلية متقدمة

### 14. تعدد المستخدمين والصلاحيات
- أضف إمكانية وجود أكثر من مستخدم (مثلا: صاحب العمل + سائق الجمع).
- أضف صلاحيات مختلفة (مشاهدة فقط / تعديل / إدارة).

### 15. ربط مع أنظمة المحاسبة
- أضف تكامل مع أنظمة المحاسبة الشائعة أو على الأقل تصدير بصيغة متوافقة.

### 16. تحليلات متقدمة ورسوم بيانية
- أضف رسوم بيانية لتتبع اتجاهات الإنتاج على مدار الأشهر.
- أضف مقارنة أداء الموردين.
- أضف تنبيهات ذكية عند انخفاض إنتاج مورد بشكل ملحوظ.
